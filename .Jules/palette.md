## 2025-02-15 - [A11y Navigation Bypass and Custom MUI Link Focus]
**Learning:** When building an app with heavy, fixed canvas overlays (like `TraceCanvas` and `RippleCanvas`) and immersive visual elements, maintaining top-level keyboard navigation bypass links (e.g., "Skip to main content") is crucial for screen-reader and keyboard users to not get trapped in navigation or visual layers. Furthermore, when using custom styled components like MUI's `<Box component="a">` or `<ListItem component="a">`, the browser's default focus outlines are frequently stripped or hidden by CSS resets, meaning explicit `&:focus-visible` styles (often mimicking `&:hover` effects with added borders or glows) must be manually written to preserve keyboard accessibility.
**Action:** Always include a "Skip to content" link when building heavily styled/canvas-based portfolios. Always verify and manually add `&:focus-visible` states to any custom or icon-only interactive elements in MUI to ensure focus indicators are visible.
