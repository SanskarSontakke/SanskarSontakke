- Bridging **astronomy and ML**: exoplanet transit detection, galaxy morphology, and light-curve classification on real Kepler/TESS data
- **Reinforcement learning** — building agents that learn to play games from scratch
- Getting fluent in the **scientific Python** stack (NumPy, Jupyter, and astro tools like Astropy & Lightkurve)
- Writing cleaner, reproducible, well-documented code and contributing to open-source
